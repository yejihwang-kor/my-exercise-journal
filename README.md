# 나의 운동 일지 PWA

운동 레슨과 개인 훈련 내용을 날짜별로 기록하는 설치형 웹앱입니다. 게시물은 레슨, 단체훈련, 개인훈련, 매치로 분류할 수 있고 상세 화면은 분류별 테마 색으로 표시됩니다. 캘린더의 게시 날짜에는 카테고리별 색 점이 표시되며, 날짜별 목록은 최신순 또는 카테고리별로 볼 수 있습니다. 설정에서 운동 종목을 고르면 메인 화면 제목과 운동 아이콘이 바뀝니다. 축구와 풋살을 각각 고를 수 있고, 야구, 농구, 테니스, 배드민턴, 러닝, 수영, 탁구, 골프, 자전거, 보드, 헬스, 필라테스, 요가, 복싱, 등산, 줄넘기, 스케이트, 스키·스노보드, 클라이밍을 포함해 마지막 항목인 운동도 선택할 수 있습니다. 홈 화면 앱 아이콘은 멀티스포츠 기록을 상징하는 공·아령·기록장 디자인입니다.

## 실행

`index.html`을 브라우저에서 열어 기본 기능을 사용할 수 있습니다. 홈 화면 설치와 오프라인 캐시를 사용하려면 HTTPS로 제공되는 주소가 필요합니다. 배포할 때는 이 폴더의 파일을 무료 정적 호스팅에 올리면 됩니다.

## 저장 및 영상

일지와 영상은 IndexedDB를 통해 현재 사용 중인 브라우저와 기기에 저장됩니다. 운동 종목 설정은 브라우저 로컬 저장소에 저장됩니다. 계정이나 서버로 전송되지 않으므로 다른 기기와 자동 동기화되지 않습니다. 브라우저 데이터를 지우면 함께 삭제될 수 있어 중요한 일지는 별도로 보관해주세요. 일지 하나에 동영상을 여러 개 첨부하고 각 영상 제목을 저장할 수 있습니다. 영상은 파일당 최대 250MB까지 선택할 수 있지만, 실제 저장 가능한 크기는 기기의 여유 공간에 따라 달라집니다.

## 설치

- Android: Chrome에서 호스팅 주소를 열고 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.
- iPhone: Safari에서 호스팅 주소를 열고 **공유 → 홈 화면에 추가**를 선택합니다.

사용자 정의 도메인이나 유료 기능 없이 무료 정적 호스팅을 이용할 수 있습니다. 호스팅 업체의 무료 제공 조건은 변경될 수 있습니다.
